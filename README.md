# Spatial Patterns of Global Warming from Climate Emulators

This repository contains analysis workflows for understanding future warming patterns by combining climate model outputs and machine learning methods.
The repository focuses on two core components:

#### Spatial Patterns of Warming

Analysis of spatial (lat–lon) patterns of surface warming
Pattern extraction and characterization using machine learning algorithms

#### Global-Mean Temperature Projections

Global mean temperature trajectories derived from the FaIR climate model
Used as inputs or constraints for spatial pattern scaling and projection analyses
